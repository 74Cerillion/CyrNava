# ADR-002: Native document JSON is canonical

Status: Accepted implementation, recorded retrospectively during M6.

## Context

Markdown/HTML conversions can lose editor structure and image properties.

## Decision

Store BlockNote-native document_json with format_version 1 and revision in SQLite; validate supported blocks, limits and owned asset URLs.

## Alternatives considered

Canonical Markdown or HTML; opaque browser-only state. Alternatives listed here are an M6 comparison; no undocumented past deliberation is asserted.

## Rationale and evidence

M1 implemented lossless structured storage and optimistic revisions; later blocks extend format 1. Evidence: current source, root milestone reports and available Git history through M5 `5fa4dab`.

## Accepted tradeoffs

Storage remains coupled to an explicit supported BlockNote schema; future incompatible formats need migration.

## Consequences

Preserve JSON structure through save/reload/backup; do not treat exported presentation formats as canonical.
