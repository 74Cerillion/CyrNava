# ADR-004: Incremental vertical-slice development

Status: Accepted implementation, recorded retrospectively during M6.

## Context

The owner needs comprehensible increments and data-preserving changes.

## Decision

Develop foundation, durable notes, hierarchy, images, reliability and release preparation as reviewed milestones.

## Alternatives considered

Implement all planned engagement features at once; redesign completed layers for speculative future use. Alternatives listed here are an M6 comparison; no undocumented past deliberation is asserted.

## Rationale and evidence

The available five commits and M0–M5 reports show incremental implementation. No independent M3 commit/directive is available; the M2 report and later state are the evidence, not an invented chronology. Evidence: current source, root milestone reports and available Git history through M5 `5fa4dab`.

## Accepted tradeoffs

Some hardening arrives after the initial capability; retrospective reports must distinguish historical behavior from current guarantees.

## Consequences

M6 preserves working persistence and stays within release engineering; Phase 2 remains separately authorized.
