# ADR-005: React/TypeScript/Vite and Python technology selection

Status: Accepted implementation, recorded retrospectively during M6.

## Context

The owner specified a readable local web stack and core BlockNote packages.

## Decision

Use React/TypeScript with Vite; FastAPI/Pydantic on Python; SQLite standard library. Pin direct versions and npm lock resolution.

## Alternatives considered

Another frontend framework; desktop packaging; an ORM or database server. These are review alternatives, not documented historical evaluations. Alternatives listed here are an M6 comparison; no undocumented past deliberation is asserted.

## Rationale and evidence

The stack is explicit in the project requirements and present from the foundation. Existing Vitest, pytest and Playwright cover separate layers. Evidence: current source, root milestone reports and available Git history through M5 `5fa4dab`.

## Accepted tradeoffs

Two language environments and a frontend build are required; the editor bundle is substantial.

## Consequences

Document both environments. M6 adds no runtime library, ORM, container or state framework; installed exact versions remain unchanged.
